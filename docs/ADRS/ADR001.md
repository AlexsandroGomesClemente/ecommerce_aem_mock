# ADR-001: Containerização do Ecossistema com Docker

Status: Aceito
Contexto:
O projeto envolve múltiplas tecnologias: AEM (instâncias Author e Publish), BFF/Microsserviços em Java, Front-end em Vue.js e um Banco de Dados Relacional. Configurar tudo isso nativamente nas máquinas dos desenvolvedores gera inconsistências ("na minha máquina funciona") e o processo de CI/CD precisa de ambientes idênticos e isolados.Decisão:
Adotar Docker para empacotar todas as aplicações e Docker Compose para orquestração do ambiente de desenvolvimento local.Consequências:

Positivas: Padronização absoluta entre os ambientes de Dev, QA e Produção. Onboarding de novos desenvolvedores muito mais rápido (basta rodar docker-compose up).

Negativas: Instâncias do AEM rodando em Docker são pesadas e consomem bastante memória RAM e CPU. Será necessário estipular um hardware mínimo (ex: 16GB+ de RAM) para as máquinas dos desenvolvedores.
