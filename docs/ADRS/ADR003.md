# ADR-003: GraphQL como Camada de API (BFF)

Status: Aceito
Contexto:
O front-end em Vue.js precisa renderizar telas combinando conteúdos editoriais (vindos do AEM) e dados transacionais/regras de negócio (vindos do banco relacional via Java). Fazer múltiplas chamadas REST separadas geraria over-fetching (trazer dados a mais) e aumentaria o tempo de carregamento da página do e-commerce.Decisão:
Implementar uma camada de agregação com GraphQL no Back-end Java (ou utilizando o suporte nativo a GraphQL do AEM integrado ao Java). O Vue.js fará requisições para um único endpoint GraphQL.Consequências:

Positivas: O Vue.js ganha o poder de pedir estritamente os dados que precisa em uma única requisição. O esquema (Schema) fortemente tipado atua como documentação viva entre os times de Front e Back.

Negativas: O cache no GraphQL é mais complexo do que no REST tradicional. O time de Java precisará tratar o problema de "N+1 queries" utilizando padrões como o DataLoader para não sobrecarregar o banco relacional.
