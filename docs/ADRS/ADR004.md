# ADR-004: Pipeline de Build do Front-end (Vue.js no AEM)

Status: Aceito
Contexto:
O código fonte do Vue.js (arquivos .vue, SCSS, TypeScript) não pode ser rodado nativamente dentro do AEM. Ele precisa ser transpilado e minificado em arquivos JavaScript e CSS puros, que o AEM reconheça como ClientLibs (Client Libraries).Decisão:
Utilizar o Vite (ou Webpack) para o processo de build do Vue.js. O processo de CI/CD no Docker pegará o output do Vite, encapsulará na estrutura de pastas exigida pelo AEM (ClientLibs) e fará o deploy junto com o código Java.Consequências:

Positivas: Permite que o time de front-end utilize as ferramentas mais modernas do ecossistema Vue (Hot Module Replacement no desenvolvimento local isolado), enquanto atende às exigências de entrega do AEM.

Negativas: Adiciona passos extras na esteira de build (CI/CD) e exige scripts customizados para mapear os arquivos gerados (com hash) para os arquivos XML de configuração do AEM.
