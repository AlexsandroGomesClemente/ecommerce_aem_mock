# ADR-002: Adoção de Banco de Dados Relacional (PostgreSQL) para Dados Transacionais

Status: Aceito
Contexto:
Embora o AEM possua seu próprio repositório de dados (o JCR - Java Content Repository, focado em documentos e conteúdo não-estruturado), o e-commerce lidará com dados transacionais e estruturados (perfis de usuários logados, histórico de navegação robusto, mapeamento de regras de negócio complexas).Decisão:
Utilizar o PostgreSQL como banco de dados relacional principal, gerenciado pela camada de back-end em Java (via Spring Data JPA/Hibernate).Consequências:

Positivas: Garantia de propriedades ACID (Atomicidade, Consistência, Isolamento, Durabilidade) para operações financeiras e de conta do usuário. Integridade referencial sólida.

Negativas: Exige o gerenciamento da separação entre o que é "Conteúdo" (vai para o JCR do AEM) e o que é "Dado Transacional" (vai para o Postgre). Adiciona a necessidade de controle de versão de schema (usando Flyway ou Liquibase).
