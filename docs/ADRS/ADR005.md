# ADR-005: Estratégia de Autenticação Stateless (OAuth 2.0 + JWT em Cookies HttpOnly)

Status: Aceito
Contexto:
O e-commerce lida com dados sensíveis dos clientes (dados de cobrança, planos, informações pessoais). O sistema precisa autenticar milhares de usuários simultâneos sem que o back-end Java engargale tentando validar sessões ativas no banco de dados. Além disso, o Vue.js precisa acessar essas APIs protegidas no GraphQL de forma segura, prevenindo ataques de injeção de script (XSS).Decisão:
Adotar autenticação Stateless baseada no protocolo OAuth 2.0 utilizando JWT (JSON Web Tokens).

O processo de login validará as credenciais e emitirá um token JWT assinado.

O token não será salvo no localStorage do navegador, mas sim entregue via Cookies HttpOnly e Secure.

O back-end Java validará criptograficamente a assinatura do token no header da requisição GraphQL, sem precisar consultar o PostgreSQL a cada chamada.Consequências:

Positivas: Escalabilidade horizontal extrema (como o servidor Java não guarda estado de sessão, qualquer container Docker pode atender qualquer requisição). Proteção robusta contra ataques XSS, pois o JavaScript do front-end não tem acesso direto ao cookie HttpOnly.

Negativas: Como o token é stateless e o servidor não guarda a sessão, invalidar o token antes da expiração (em caso de roubo de conta ou logout forçado) exige a criação de uma Deny List (Lista de revogação), possivelmente adicionando um cache em memória (como Redis) à arquitetura.
