# Projeto Ecommercer 

## Objetivo 
 Um projeto simples para apresentação em uma entrevistas com o gestor, hoje a vaga pede alguns requisitos e eu quero atendelos nesse projeto para realizar a apresentação.
 O projeto é um ecommerce simples, onde terei uma imagem e um container rodando a aplicação.
 O front-end vai utilizar vue e aem, enquanto o back end é feito em JAVA.

 ## STACK
 FRONT -> VUE, AEM
 BACK-END -> JAVA
 BANCO -> PostgreeSQL
 CONSUMO -> VIA GRAPHQL e API
 SEGURANÇA -> Autenticação e melhores praticas
 TESTES -> Preciso de testes unitarios e end-to-end, também preciso de testes de carga com pelo menos 500 e 5000 usuarios usando simultaniamente.
 TELEMETRIA -> Para monitoramento dos logs .
